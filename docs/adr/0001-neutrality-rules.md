# 中立規則是硬性限制

本站是市民整理的政見網站，只要有一處看起來偏向某位候選人，整站的可信度就會受損。所以以下規則屬於硬性限制，任何設計或內容調整都不得違反：

- 候選人排列：已抽籤照號次，抽籤前照姓名筆畫。
- 不用任何政黨色（藍、綠、白、橘），也不用候選人的識別色（海洋藍、粉紅、桃紅、紫）。三人共用同一個中性色，以形狀區分。
- 3D 場景不呈現政見數量，每個議題區每人一個同尺寸標記，只表示有或沒有政見。
- 3D 場景的動態元素（小人、車輛、粒子等）在每一格的數量與強度固定，與該區政見數及哪位候選人有政見無關。三個標記的動畫完全相同。靜態裝飾（主題建物、街道家具、植栽）同樣每格數量固定，主題建物依議題區決定，不依政見數量或哪位候選人有政見。
- 候選人在 3D 場景中以同一款中性人物呈現，身形、精緻度、動作相同，不模仿長相，只以名牌與形狀區分。
- 候選人資料欄位固定為姓名、政黨、出生年、學歷、經歷，三人相同；正式肖像只依下節有限例外加入。來源只用中選會（選舉資料庫、選舉公報），經歷逐字呈現，不改寫。不收政績、爭議、財產、媒體報導與候選人自我介紹。
- 島上元素只取與市政建設無關的在地元素，不放任何與市長任期綁定的地標。
- 只收一手來源，不收媒體報導。
- 每人篇幅與字級相同。不評分、不排名、不推薦。
- 不收民調，不放捐款或催票連結，不放任何陣營的 logo 或照片；正式肖像只依下節有限例外使用。
- 名稱、文案、網域不得使用任何候選人的品牌用語或其諧音。
- 參考網站（heart-island 是候選人競選網站，lumama 是批評市政的反諷作品）只借技術做法與通用版面結構，不借其配色、標誌字型組合、預設深夜場景與陰森元素。本站預設白天場景，沿用自己的配色與標題樣式。
- 每條政見附出處連結與出處快照，通過核對才能公開（見 ADR 0002）。
- 分類規則公開在頁面上。
- 揭露本站由 AI 依公開資料自動整理，並公開抽取與核對的提示詞、檢核表與完整流程。
- 上線不經人工放行，改由自動化關卡把關：品牌用語掃描、禁用色檢查、公開資料全數通過核對、三人版面一致。任一項未過就不部署。

## 正式肖像有限例外（2026-10-24 核准）

- 只放候選人資料卡，包含索引面板「候選人」分頁共用的資料卡。不放政見卡片、表格欄頭或 3D 場景，不改變候選人人物造型。
- 三人使用同一年、同類中選會選舉公報的正式肖像。保留原始黑白影像，等比例縮放、同尺寸留白、相同背景處理，不裁臉、不修臉、不生成、不加宣傳字樣。照片原有服飾配件不作為本站識別圖案。
- 依公報上的姓名欄與照片位置核對對應，不從臉部推斷身分。記錄原公報、年份、取得日期、影像雜湊、抽取物件及頁面、授權依據與限制。
- 單獨抽出的照片可能仍有著作權。使用依據須明確適用該素材，不能以公報屬公文直接推論照片沒有著作權。採中選會網站資料開放宣言與政府資料開放授權條款時，逐份檢查特別排除聲明，保留署名、註明出處、不暗示官方認可。著作權授權不代替肖像等人格權的判斷，只用於中立辨識，不作宣傳代言。
- 三人的資料、照片檔案、來源對應與授權核對全部齊全才同時公開；任何一人缺漏、無法確認授權或載入失敗，三人一致回退為原本的文字資料卡，不留破圖。照片只放本站，不熱連結外站。
- 每張照片尺寸、位置、說明、出處與互動方式相同，不單獨放大或美化一人。其餘中立規則不變。

## 讀者主動開啟的暫時狀態與讀者自己的資料（2026-10-24 補充）

以下功能把「對照」與「查證」做成讀者看得見的動作。每一項都在上面的規則之內，這裡寫明邊界，避免日後實作時越線：

- **走到同一格**：讀者點開一個議題區時，三位候選人人物以同一套步伐動畫、同時出發、同時抵達，各自走到該格自己的標記旁；沒有政見的人照樣走到灰色標記旁。目的地只依標記位置，速度依距離調整到同時抵達，動畫參數與路徑規則三人相同，仍由上線關卡「人物一致」檢查。政見卡片等三人抵達才開，步行全程看得到。關閉卡片後三人同時走回候選人廣場。
- **閱讀進度與我的對照單**：讀者看過哪些議題區、勾選了哪些政見，只存在讀者自己的瀏覽器與讀者自己分享的網址裡。本站不收集、不統計、不顯示其他讀者的勾選，沒有獎勵、排行或完成訊息。對照單仍是三欄並排，勾選只決定「哪些議題區」出現，不決定「哪位候選人」出現。
- **市民補件**：空欄位旁提供回報一手來源的出口，預填議題區與候選人。只收出處連結，不收意見或評價；處理過程公開在 Issues，補上的政見一樣走兩層核對。這不是「讀者對候選人的留言」，與下節的暫緩項目不衝突。
- **選舉時程**：頁首列出的日期與距投票日天數只取中選會或選舉委員會的公告，與候選人無關。
- **朗讀**：政見的音檔由語音合成服務以固定設定預先生成，三人同一聲線、同一語速、同一文字樣板（摘要加原文引述，不加整理者的其他文字）。全有或全無：三人公開政見的音檔要齊全，缺任何一條整站都不公開音檔，由上線關卡「音檔只來自政見語音清單」檢查。語音設定與每條音檔的對照清單照原文公開在整理方法頁。原文引述的文字仍以畫面為準，音檔只是方便收聽。

## 考慮過並排除的功能

- **過去四年市政成績對照**（2026-10-24 排除）：現任市長不參選，但把政見對照現任政績等於評價現任，間接利或不利同黨候選人，而且「成績」的指標與基準由整理者挑選，正是 ADR 0002 要排除的個人偏差。若日後要呈現「現況」，只能放開放資料的原始數字，不解讀、不比較，且另立 ADR。
- **讀者對候選人的留言或許願**（2026-10-24 暫緩，未決）：讀者寫下對候選人的看法等於本站刊載評價，累積後形同非正式民調，與「不評分、不推薦、不收民調」衝突，也需要後端與審核。選前不做；若日後重議，先解決這三點。
- **貓狗或在地動物當導覽吉祥物**（2026-10-24 排除）：本站的聲音應是「一位市民」，島上既有的 Q 版市民已能擔任導覽；常見的橘貓用到禁用色，石虎保育本身是本次選舉的議題，放上去等於選邊。每格固定數量的同款小鳥可當靜態或動態裝飾，但不當角色、不說話。
- **政見之間的關聯線、熱度或「最多人看」**（2026-10-24 排除）：任何把政見互相連起來或依點閱排序的呈現，都會變成另一種排名或推薦。
- **遮名閱讀**（2026-10-24 上線後移除：讀者反映沒有好處、增加混亂）：政見卡片上由讀者主動開啟，先遮住三欄的姓名與政黨、打亂欄位順序，讀完再揭曉。
