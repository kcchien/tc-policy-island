# 只陳述本站的收錄狀態，不從缺漏推論候選人未提出

日期：2026-10-24

本站依取得的一手來源整理政見，只公開通過兩道核對的資料。資料可能尚未取得、尚未整理或尚未通過核對；空欄本身無法判斷是哪一種原因，也不能證明候選人未提出政見。把空欄寫成「未提出相關政見」超過現有資料能支持的主張，會讓三人對照產生誤導。

## 決策

- **收錄狀態**：本站截至資料截止日，在一個議題區是否收錄某位候選人通過核對的政見。空欄統一寫「本站尚未收錄這個議題的政見（截至 YYYY-MM-DD）」。尚未收錄不代表候選人未提出。
- **來源狀態**：本站目前取得的候選人政見一手來源情況，不代表候選人所有公開發言的全貌。只依既有紀錄說明，不宣稱外界沒有來源，也不猜測未蒐集的原因。原始狀態「尚無一手來源」在畫面寫成「本站尚未取得可核對的政見一手來源」。公開政見或原始政見條目引用的出處可支持已取得政見來源；只有候選人基本資料的出處不算。沒有上述紀錄且沒有已知來源狀態時，只說「本站尚未公開政見一手來源的收錄紀錄」。
- **篩選結果**：本站已收錄資料中符合讀者目前條件的結果。已收錄但篩選後沒有結果時寫「沒有符合篩選條件的政見」，不改變原本的收錄狀態；原本尚未收錄的空欄維持收錄狀態。
- 三位候選人沿用相同的排序、版面、字級、標記大小與互動。島上標記仍只表示是否有收錄，篩選時表示是否有符合結果，不呈現政見數量。圖例、導覽、無障礙名稱、卡片、表格與對照單（含列印）使用同一套說明。
- 核對只確認引用文字與原文一致，以及摘要忠實度、評價與品牌用語。通過核對不是政見內容的事實查核、可行性評估或履約保證，不新增核對標章，也不改為人工逐筆放行。
- 整理方法公開蒐集範圍與缺漏可能性，不聲稱已全面搜尋所有網站。取得來源後仍依原有抽取與核對流程收錄，市民補件出口保留。

這是對 ADR 0001 標記與三人並排規則的語意釐清，不更動其硬性限制，也不批次改寫歷史 ADR、原文引述或候選人資料原文。不修改資料結構、原始政見、來源或核對結果；狀態由呈現層依既有公開資料推導。

## 考慮過的做法

- 將空欄視為候選人未提出：不採用，因為本站收錄不完整，無法支持這個結論。
- 隱藏空欄或只顯示有收錄的人：不採用，三人並排仍有助讀者對照，應明確說明本站的資料限制。
- 只修改卡片空欄：不採用，圖例、導覽、篩選與列印仍可能傳達不同意思，必須同步。
