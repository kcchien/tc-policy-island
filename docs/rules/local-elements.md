# 元素清單

島上的在地感元素名冊，資料檔是 `data/raw/local-elements.json`，會隨公開資料集公開。依 ADR 0001，元素只取與市政建設無關的自然景觀、小吃、老建築，每項附「與任何市長任期的政績無關」的理由。

## 收錄判準

- 只收三類：自然景觀、小吃、老建築。
- 元素本身不得是任何一任市長（含合併前的台中縣長、台中市長）任內興建、整修或主辦的成果。老建築只呈現建築本身，不呈現後來的整修工程；自然景觀只呈現地形與生物，不呈現步道、風機等人工設施。
- 元素本身，或它所屬的景區、設施出現在任何候選人的政見中，就不收，避免看起來在呼應某人的政見。只是位在政見提到的行政區（例如大甲、清水）不算，行政區名稱幾乎都會出現在某條政見裡。
- 動物、植物不收，只收三類中的地形、食物與建築。
- 有疑慮就不收。
- 小吃只呈現食物本身，不呈現任何店家品牌。
- 宗教場所不收，避免與選舉期間的宮廟活動產生聯想。

## 放置

每個議題區配一個元素，見 `data/raw/issue-areas.json` 的 `localElementId`。兩個裝飾格各放一個元素，見 `data/raw/decorative-tiles.json`。元素與議題區的配對只為了島的外觀，不代表元素與該議題有關。
