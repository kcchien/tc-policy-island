# 分類規則

本文件說明議題區怎麼劃分、一條政見怎麼歸到議題區。議題區的拆法會影響各候選人在每一區看起來有幾條政見，所以規則全文公開。議題區清單的資料檔是 `data/raw/issue-areas.json`，研究筆記中每條已知政見的歸屬見 [政見與議題區對照表](policy-area-mapping.md)。

## 1. 為什麼不照候選人的政見架構

每位候選人都有自己的政見分類，例如江啟臣的「五大面向」、何欣純的「領域政見」與「區域政見」，洪麗華沒有分類。照任何一人的架構分區，那個人的政見會分布得整齊，其他人的政見會顯得零散或擠在少數幾區，等於用版面替其中一人背書。

本站改用台中市政府的局處職掌分區。局處是市長當選後實際執行政見的單位，與任何候選人無關，三位候選人一體適用。

## 2. 劃分議題區

依據是《臺中市政府組織自治條例》第六條（民國 113 年 11 月 8 日修正）所列的 31 個一級機關。以下判準只看局處的法定職掌，不看任何候選人的政見多寡，三位候選人一體適用。

1. **一個一級機關是一個單位。** 二級機關併入它的上級機關，例如動物保護防疫處併入農業局、住宅發展工程處併入都市發展局。
2. **只依三種情形合併，合併與否和政見數量無關：**
   - 同一條業務鏈的規劃、興建與營運分屬不同局處時合併。交通局與捷運工程局合併；建設局的道路橋梁業務併入交通，因為道路是交通設施。
   - 同屬 24 小時第一線緊急勤務的局處合併：警察局（110）與消防局（119）。
   - 不直接對市民提供服務、負責市府自身運作的幕僚機關合併為「市政治理」：秘書處、財政局、法制局、新聞局、地方稅務局、主計處、人事處、政風處、研究發展考核委員會。
3. **只依一種情形拆分：** 一個局處的業務被第 2 點的合併判準切開時，剩下的業務自成一區。建設局的道路橋梁併入交通後，公園綠地業務自成「公園綠地」。除此之外不拆分任何局處，不因某位候選人在某個局處的政見特別多就拆細。
4. **任一候選人有政見就保留，一條也算。** 一個單位只要有任何一位候選人的至少一條政見歸入，就成為議題區。沒有任何候選人政見的單位不設議題區（例如地政局）。這條判準不看是哪一位候選人、也不看政見條數，所以會出現只有一位候選人有政見的議題區，例如「民政」與「數位發展」。
5. **新的政見對到沒有議題區的局處時，依同一套判準新增議題區**，不併入相近的議題區。

## 3. 一條政見歸入一個議題區

1. **一條政見只歸一區。** 不重複計入，否則跨領域政見多的候選人會在多區重複出現。
2. **歸入主要辦理局處所在的議題區。** 主要辦理局處是政見要做的事（設施、補助、服務、制度）由哪個局處主辦。
3. **跨議題時，看政見的主要成果。** 例如「通學步道」的成果是道路設施，歸交通，不歸教育；「育兒友善廁所」的成果是公廁設施，歸環境保護。
4. **新設機關或委員會，依它要主管的業務歸區。** 例如「衛生局下新設長照處」歸醫療衛生。新機關的業務橫跨多個局處、沒有單一主管業務時，歸市政治理，例如「成立青年局」。
5. **沒有單一主辦局處的事項歸市政治理。** 包括向中央爭取的事項、全市性的總體目標、市府組織與人事調整。
6. **一句話裡有幾件可以分開執行的事，拆成幾條政見分別歸區。** 例如「女性勞工健檢補助提高；乳癌篩檢免費擴大；公共場所設夜間安全停車區」拆成勞工、醫療衛生、交通三條。
7. **口號、願景與品牌用語不是政見，不歸區。** 例如「準首都」。

## 4. 議題區數量與地圖無關

議題區的數量是第 2 節判準的結果，不由島的格數決定。做法的順序是：先依分類規則定出議題區清單，再把議題區放上島。

島的六角格依台中市行政界線取樣排成市輪廓（見 [島嶼格子配置](island-layout.md)）。格數多於議題區時，多出的格子是沒有議題區的裝飾格，放在地感元素或空地；格數不夠時調整取樣解析度，不刪減或合併議題區。
