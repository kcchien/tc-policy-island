# 政見與議題區對照表

本表把研究筆記 `docs/research/candidates-2026.md` 第 3 節列出的每條已知政見，依 [分類規則](classification-rules.md) 對到恰好一個議題區，用來確認議題區清單涵蓋所有已知政見。

- 「政見」欄是研究筆記的條目文字，屬候選人或媒體的原文，可能含品牌用語；本表不是網站文案。
- 研究筆記一個條目含幾件可分開執行的事時，依分類規則第 3 節第 6 點拆成幾列，編號加 a、b、c。
- 「依據」欄只在歸區需要判斷時填寫。標「未查證」的是研究筆記只有標題或摘要，依標題判斷，抽取正式資料時以一手來源內容為準重新歸區。
- 研究筆記第 3 節的願景用語與口號（例如「準首都」、洪麗華的參選理念）不是政見，不列入。何欣純的「333豐原山線大創新」研究筆記只有影片標題、沒有內容，無法判斷是什麼政見，不列入。
- `test/rules.test.js` 會檢查每列的議題區都存在、每個議題區至少有一列。
