# 島嶼格子配置

島由同尺寸的尖頂六角格組成，每格用軸向座標 `[q, r]` 定位：`q` 往東增加，`r` 往南增加。議題區的座標在 `data/raw/issue-areas.json`，沒有議題區的裝飾格在 `data/raw/decorative-tiles.json`。

## 做法

1. 先依 [分類規則](classification-rules.md) 定出議題區清單（目前 20 個）。議題區數量與地圖無關。
2. 取台中市行政界線（內政部縣市界，g0v twgeojson 整理版），以經緯度 24.22°N、120.95°E 為原點投影成公里座標。
3. 在界線上鋪六角格，格心到頂點 6 公里。每格取 121 個樣點，樣點有 45% 以上落在市界內的格子算在島上。在格徑與格網位移的組合中，選出格數不少於議題區數、連成一塊、平均覆蓋率最高的一組：22 格，平均覆蓋率 0.90。
4. 22 格中 20 格放議題區，最東端（南湖大山一帶）與西南角（大肚溪口一帶）2 格是裝飾格。
5. 議題區放在哪一格只為了島的外觀，不代表該議題與那個地區有關。

格數不夠放下議題區時，調小格徑重新取樣，不刪減或合併議題區。

## 配置圖

西側是海線與市區的平原，東側是和平區往東北延伸的山地長條，是台中市行政區域的外形。
