# 禁用色範圍

範圍資料檔是 `data/rules/forbidden-colors.json`。上線關卡「禁用色檢查」把網站 CSS、HTML、SVG 與 JS（3D 材質色碼寫在 JS）中的每個色碼換成 HSL，色相、飽和度、亮度都落在某一範圍內就擋下。

## 範圍

| 名稱 | 類別 | 色相（度） | 飽和度 | 亮度 | 說明 |
|---|---|---|---|---|---|
| 藍 | 政黨色 | 195～255 | 0.2 以上 | 0.08～0.96 | |
| 綠 | 政黨色 | 75～170 | 0.2 以上 | 0.08～0.96 | |
| 白 | 政黨色 | 不限 | 不限 | 0.96 以上 | 純白與接近純白。本站米白底色 `#f4efe6` 亮度 0.93，不在範圍內 |
| 橘 | 政黨色 | 18～45 | 0.55 以上 | 0.30～0.85 | 鮮豔的橘色。本站紅土赭色飽和度低，不在範圍內 |
| 海洋藍 | 候選人識別色 | 180～215 | 0.2 以上 | 0.08～0.96 | |
| 粉紅 | 候選人識別色 | 320～15（跨 0 度） | 0.3 以上 | 0.60～0.96 | 含偏紅的淺粉紅 |
| 桃紅 | 候選人識別色 | 300～350 | 0.3 以上 | 0.25～0.60 | |
| 紫 | 候選人識別色 | 255～300 | 0.15 以上 | 0.08～0.96 | 含薰衣草紫 |

飽和度下限讓灰色、炭灰這類幾乎沒有色相的中性色不被誤擋，例如本站白天近島水面的灰青色 `#abc4c2` 飽和度 0.17。

## 抽取的色碼

- 顏色寫法：十六進位 `#rgb`、`#rgba`、`#rrggbb`、`#rrggbbaa`，`rgb()`、`rgba()`、`hsl()`、`hsla()`，以及 CSS 具名顏色（例如 `hotpink`）。
- CSS 只看大括號內宣告的值，選擇器裡的 `#id`、`:hover` 不算。
- HTML 與 SVG 只看 `<style>`、`style` 屬性與 `fill`、`stroke`、`color`、`stop-color` 等顏色屬性的值。
- JS 只看 `0xrrggbb`（three.js 材質寫法），以及整段就是一個顏色的字串（例如 `'#8e4b32'`）。
- `var()`、`url()` 的內容、註解、完全透明的顏色、`vendor/` 的第三方程式碼都不檢查。

## 本站配色的檢查結果

`site/css/main.css` 現有 8 個色碼全數不在範圍內，不需調整（2026-10-23）。

島嶼檢視的 3D 材質色碼集中在 `site/js/island-models.js` 的 `PALETTE`，共 43 個，全數不在範圍內（2026-10-23）。候選人人物三人同一組中性色：身體暖灰 `0x9c948a`（色相 33 度、飽和度 0.07）、頭部米色 `0xdccdb8`（色相 35 度、飽和度 0.34，橘色範圍要飽和度 0.55 以上）、髮殼深灰褐 `0x62564c`、眼睛與微笑線 `0x3a332e`、腮紅灰玫瑰色 `0xb08578`（色相 14 度、飽和度 0.26、亮度 0.58，粉紅範圍要飽和度 0.3 且亮度 0.6 以上；市民的腮紅同色）。市民與配件的色碼在 `site/js/island-motion-view.js` 的 `MOTION_PALETTE`（斗笠沿用 `PALETTE.straw`、腮紅沿用 `PALETTE.figureCheek`），都是色相 16～47 度、飽和度 0.44 以下的大地色；學童帽用米色 `0xcdbb94`，安全帽用土黃 `0xc4a467`（飽和度 0.44），不用亮黃（2026-10-23）。樹叢與田地用低飽和的橄欖灰（例如 `0x8c8a62`，色相 57 度、飽和度 0.18，不在綠色的色相範圍 75～170 度內），避開綠色範圍；`test/rules.test.js` 檢查每個 `0xrrggbb` 都被關卡抽到。

主題場景的色碼在 `site/js/island-heroes.js` 的 `HERO_COLORS`，共 28 個，全數不在範圍內（2026-10-23），`test/island-heroes.test.js` 逐一檢查。屋頂與消防車用低亮度的赭紅（例如 `0xb5583f`，色相 13 度、亮度 0.48，粉紅範圍要亮度 0.6 以上）；公車與學童帽用色相 48 度的芥末黃（`0xd8bb4a`，橘色範圍到 45 度為止）；遮陽篷與候車亭用色相約 172 度的青瓷色（`0x5e9a92`），落在綠（75～170 度）與海洋藍（180～215 度）之間；玫瑰灰 `0xb07a72` 亮度 0.57、飽和度 0.29，不在粉紅範圍。色名不用 CSS 具名色（例如 red、teal），關卡會把字串當成色碼。

外圍地形的色碼在 `site/js/island-terrain.js` 的 `TERRAIN_PALETTE`，共 35 個（海床、浪花、沙灘、5 種田塊、草坡、山坡、岩、稜線、樹幹、6 種闊葉樹冠、4 種針葉樹冠、牆、2 種屋頂、雲、鳥、遠山的日夜兩色、海上小島、燈塔塔身與環帶、船身、船帆），全數不在範圍內（2026-10-23）。樹冠與田塊用色相 45～72 度的橄欖色，色相在綠色範圍 75 度以下。山坡色依高度在相鄰兩色之間內插，`test/rules.test.js` 逐段檢查內插色也不在範圍內。浪花用亮度 0.85 的米灰（`0xe2dbcd`），雲用亮度 0.88 的米灰（`0xe6e1d8`），船帆用亮度 0.88 的米灰（`0xeae3d7`），都不用白色。霧團顏色每幀取時段關鍵影格的霧色，不另寫色碼。遠山剪影的顏色由日夜兩色依夜間係數內插，再往地平線色混，測試檢查每一圈在任兩個時段補間途中的顏色。

晝夜的色碼在 `site/js/island-daylight.js` 的 `KEYFRAMES`（四個時段，每段 11 色）與星星色 `STAR_COLOR`，共 45 個，全數不在範圍內（2026-10-23）。外圍陸地另依時段乘上陸地色調 `landTint`（白天不改色、黃昏偏暖、夜晚壓暗偏冷），`test/rules.test.js` 檢查外圍每個色碼乘上任兩時段補間途中的色調後仍不在範圍內；針葉樹冠原本的 `0x6b7345`（色相 70 度）在夜晚冷色調下會偏進綠色範圍，改為色相 64 度的 `0x707345`。光照強度與欄位結構參考黏土微縮城市的日夜表，但參考數值的藍色天空與水色都落在藍或海洋藍範圍，改成飽和度 0.2 以下的灰青（例如白天天頂 `0xb8cccb`、色相 177 度、飽和度 0.16）。色相 170～180 度雖然不在任何範圍內，但這段空檔太窄：灰青往暖色或冷色補間時，中途的顏色會掉進綠或海洋藍，所以天空與水的飽和度一律壓在 0.2 以下。太陽色與光暈色的飽和度壓在 0.5 左右，與高亮度的白天色補間時才不會落進橘色範圍。著色器裡的混色（天空往太陽光暈色、星星往星星色、水面深淺漂移與往光暈色的閃光）在線性空間進行，`test/rules.test.js` 照著色器的混色比例，檢查任兩個時段之間每個補間點混出的顏色。
