# 禁用色範圍

範圍資料檔是 `data/rules/forbidden-colors.json`。上線關卡「禁用色檢查」把網站 CSS、HTML、SVG 與 JS（3D 材質色碼寫在 JS）中的每個色碼換成 HSL，色相、飽和度、亮度都落在某一範圍內就擋下。

## 範圍

| 名稱 | 類別 | 色相（度） | 飽和度 | 亮度 | 說明 |
|---|---|---|---|---|---|
| 藍 | 政黨色 | 195～255 | 0.2 以上 | 0.08～0.96 | |
| 綠 | 政黨色 | 75～170 | 0.2 以上 | 0.08～0.96 | |
| 白 | 政黨色 | 不限 | 不限 | 0.96 以上 | 純白與接近純白。本站米白底色 `#f4efe6` 亮度 0.93，不在範圍內 |
| 橘 | 政黨色 | 18～45 | 0.55 以上 | 0.30～0.85 | 鮮豔的橘色。本站紅土赭色飽和度低，不在範圍內 |
| 海洋藍 | 候選人識別色 | 180～215 | 0.2 以上 | 0.08～0.96 | |
| 粉紅 | 候選人識別色 | 320～15（跨 0 度） | 0.3 以上 | 0.60～0.96 | 含偏紅的淺粉紅 |
| 桃紅 | 候選人識別色 | 300～350 | 0.3 以上 | 0.25～0.60 | |
| 紫 | 候選人識別色 | 255～300 | 0.15 以上 | 0.08～0.96 | 含薰衣草紫 |

飽和度下限讓灰色、炭灰這類幾乎沒有色相的中性色不被誤擋，例如本站水面的灰青色 `#7d9a98` 飽和度 0.13。

## 抽取的色碼

- 顏色寫法：十六進位 `#rgb`、`#rgba`、`#rrggbb`、`#rrggbbaa`，`rgb()`、`rgba()`、`hsl()`、`hsla()`，以及 CSS 具名顏色（例如 `hotpink`）。
- CSS 只看大括號內宣告的值，選擇器裡的 `#id`、`:hover` 不算。
- HTML 與 SVG 只看 `<style>`、`style` 屬性與 `fill`、`stroke`、`color`、`stop-color` 等顏色屬性的值。
- JS 只看 `0xrrggbb`（three.js 材質寫法），以及整段就是一個顏色的字串（例如 `'#8e4b32'`）。
- `var()`、`url()` 的內容、註解、完全透明的顏色、`vendor/` 的第三方程式碼都不檢查。

## 本站配色的檢查結果

`site/css/main.css` 現有 8 個色碼全數不在範圍內，不需調整（2026-10-23）。

島嶼檢視的 3D 材質色碼集中在 `site/js/island-models.js` 的 `PALETTE`，共 43 個，全數不在範圍內（2026-10-23）。樹叢與田地用低飽和的橄欖灰（例如 `0x8c8a62`，色相 57 度、飽和度 0.18，不在綠色的色相範圍 75～170 度內），避開綠色範圍；`test/rules.test.js` 檢查每個 `0xrrggbb` 都被關卡抽到。

外圍地形的色碼在 `site/js/island-terrain.js` 的 `TERRAIN_PALETTE`，共 22 個（海床、浪花、沙灘、5 種田塊、草坡、山坡、岩、稜線、樹幹、4 種樹冠、牆、2 種屋頂、雲、鳥），全數不在範圍內（2026-10-23）。樹冠與田塊用色相 60 度上下的橄欖色，飽和度最高 0.26，色相在綠色範圍 75 度以下。山坡色依高度在相鄰兩色之間內插，`test/rules.test.js` 逐段檢查內插色也不在範圍內。海用既有的灰青水色，浪花用亮度 0.85 的米灰（`0xe2dbcd`），雲用亮度 0.88 的米灰（`0xe6e1d8`），都不用白色。霧團顏色每幀取時段關鍵影格的霧色，不另寫色碼。
